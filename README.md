# Agentic RAG Assistant 🚀

An end-to-end **Agentic Retrieval-Augmented Generation (RAG)** application built with Python, LangGraph, FastAPI, and Next.js. This project demonstrates how an AI agent can dynamically search, retrieve, and synthesize context to answer complex user queries.
